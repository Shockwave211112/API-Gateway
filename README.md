# API Gateway & Rate Limiter

## 📌 О проекте

Легковесный API Gateway на Golang, предназначенный для маршрутизации, защиты и контроля трафика основного сервиса. Писалось под бэкенд сервиса сокращения ссылок  [LinkCrop](https://github.com/Shockwave211112/LinkCrop-Laravel-API), но можно использовать и с другими проектами, использующими в качестве авторизации Bearer Token.

## 🌟 Ключевые особенности
*   **Token introspection & In-memory кэш** — Валидация токенов на указанных маршрутах
*   **Reverse Proxy & Маршрутизация** — Проксирование HTTP-запросов на внутренний сервис с автоматической простановкой заголовков (`X-Forwarded-For`, `X-Request-ID`)
*   **Rate Limiting** — Защита выделенных маршрутов от спама запросами на основе IP (с использованием Redis)
*   **Надёжность(?)** — Логирование всех запросов и ошибок, корректное завершение работы через Graceful Shutdown, служебный эндпоинт для проверки статуса сервиса (`GET /health`)

## 🛠️ Технологический стек

| Компонент                    | Технология                                                 |
|:-----------------------------|:-----------------------------------------------------------|
| Язык и ядро                  | Go (Стандартный пакет `net/http`, `httputil.ReverseProxy`) |
| Конкурентность & Кэширование | `sync.RWMutex` (In-Memory кэш токенов), Redis (`go-redis`) |
| Логирование                  | `log/slog`                                                 |
| Конфиг                       | `godotenv`                                                 |

## ⚙️ Переменные окружения (.env)

| Переменная             | Описание                                                                                                | Пример              |
|:-----------------------|:--------------------------------------------------------------------------------------------------------|:--------------------|
| `SERVER_HOST`          | Хост для привязки HTTP-сервера Gateway                                                                  | `127.0.0.1`         |
| `SERVER_PORT`          | Порт, на котором Gateway принимает входящие запросы API Gateway                                         | `127.0.0.1`         |
| `READ_TIMEOUT`         | Продолжительность чтения запроса                                                                        | `5s`                |
| `WRITE_TIMEOUT`        | Продолжительность ответа клиенту                                                                        | `10s`               |
| `IDLE_TIMEOUT`         | Время ожидания следующего запроса при включенном Keep-Alive                                             | `120s`              |
| `SHUTDOWN_TIMEOUT`     | Время на завершение активных обработок при остановке сервера                                            | `120s`              |
| `BEHIND_REVERSE_PROXY` | Флаг работы за внешним прокси (Nginx/Cloudflare) для считывания реального IP из X-Real-IP и X-Real-Port | `120s`              |
| `REDIS_HOST`           | Хост подключения к Redis                                                                                | `127.0.0.1`         |
| `REDIS_PORT`           | Порт Redis                                                                                              | `6379`              |
| `REDIS_PWD`            | Пароль для авторизации в Redis                                                                          | `secret123`         |
| `REDIS_TIMEOUT`        | Время на выполнение операций с Redis                                                                    | `30s`               |
| `APP_HOST`             | IP защищаемого сервера                                                                                  | `127.0.0.2`         |
| `APP_PORT`             | Порт защищаемого сервера                                                                                | `8000`              |
| `APP_CONNECT_TIMEOUT`  | Таймаут установления TCP-соединения с бэкендом                                                          | `10s`               |
| `APP_RESPONSE_TIMEOUT` | Таймаут ожидания заголовков ответа от бэкенда                                                           | `120s`              |
| `APP_IDLE_TIMEOUT`     | Время жизни неактивного соединения в пуле соединений с бэкендом                                         | `120s`              |
| `APP_MAX_IDLE_CONNS`   | Максимальное количество неактивных (idle) соединений                                                    | `100`               |
| `APP_LOGGED_ROUTES`    | Список маршрутов (через запятую), которым нужно Reverse Proxy (только логи и RateLimiter)               | `/auth,/home`       |
| `APP_PROTECTED_ROUTES` | Список защищенных маршрутов (через запятую), требующих валидации токена                                 | `/user/{code}`      |
| `APP_CHECK_ROUTE`      | Внутренний эндпоинт бэкенда для валидации токенов (Introspection)                                       | `/profile/settings` |
| `RATE_LIMIT_RPW`       | Максимальное количество запросов за окно на один IP                                                     | `10`                |
| `RATE_LIMIT_WINDOW`    | Длительность окна                                                                                       | `1s`                |
